# Draw.io shape library

Download [eda-shapes.xml](eda-shapes.xml). In diagrams.net, choose **File → Open Library from → Device** and select it. The palette contains 24 native editable blocks for EDA and AI-assisted design, plus solid artifact and dashed feedback connectors. Drag items onto the canvas, double-click to change the labels, and attach the connectors to the blocks.

For detailed schematic icons, import an SVG from [icons](../icons). To edit the internal vector geometry, open the SVG in Inkscape.

Regenerate the palette with `python3 scripts/build.py` from the repository root.
