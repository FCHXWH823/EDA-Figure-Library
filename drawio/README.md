# Draw.io shape library

Download [eda-shapes.xml](eda-shapes.xml). In diagrams.net, choose **File → Open Library from → Device** and select it. The palette contains 35 native editable blocks for EDA tasks, design artifacts and AI-assisted design. It also includes solid artifact and dashed feedback connectors. Use the blue rounded rectangles for tasks and double-click to edit their labels.

For detailed schematic icons, import an SVG from [icons](../icons). To edit the internal vector geometry, open the SVG in Inkscape.

Regenerate the palette with `python3 scripts/build.py` from the repository root.
